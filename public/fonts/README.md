# Bundled fonts

Outfit variable font (weight 100–900), distributed unmodified under the SIL Open Font License 1.1 in `Outfit-OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/outfit

File: `Outfit-VariableFont_wght.ttf` (upstream `Outfit[wght].ttf`).

SHA-256: `fc7287273e66929776e2ba54f144fe699080bec29f61bf649d70d871468aeade`

The app loads this font locally, including offline/native and `/app/` Core builds. Unsupported glyphs use platform system-font fallbacks; no runtime Google Fonts request is required. Existing Open Sans asset is retained for compatibility, but is no longer the app typeface.
